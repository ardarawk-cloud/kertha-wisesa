# PPS Kertha Wisesa

Website profil dan dokumentasi sejarah **Perguruan Pencak Silat Kertha Wisesa**.

## Isi
- Sejarah perguruan dan transformasi dari ESTI / Eka Sentosa Stiti.
- Pendiri dan Maha Guru.
- Nilai utama: seni, prestasi, kerohanian.
- Jejak organisasi dan pembinaan.
- Arsip sumber publik untuk verifikasi sejarah.

## Struktur
Static site tanpa framework, siap untuk Cloudflare Pages.

```
index.html
styles.css
script.js
```

## Deploy Cloudflare Pages
- Framework preset: None
- Build command: kosong
- Build output directory: /
- Production branch: main

## Catatan arsip
Materi sejarah di situs dibatasi pada informasi yang memiliki sumber publik atau arsip yang dapat diverifikasi. Foto resmi, lambang, dokumen ESTI lama, susunan pengurus lengkap, dan arsip keluarga dapat ditambahkan setelah tersedia.
